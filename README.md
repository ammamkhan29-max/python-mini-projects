# Python Mini Projects

A collection of beginner-friendly Python mini projects created for learning and practicing programming concepts.

## Projects

| Project | File | Description |
|---|---|---|
| ATM Simulator | `atm_simulator.py` | Simulates PIN verification, balance checking, deposits, withdrawals, and PIN changes for one session. |
| Contact Book | `contact_book.py` | Adds, views, searches, and deletes contacts in memory. |
| Expense Tracker | `expense_tracker.py` | Records expenses and calculates their total during a session. |
| Library Management | `library_management.py` | Adds books and tracks borrowing and returns during a session. |
| Number Guessing Game | `number_guess.py` | Guess a random number from 1 to 100. |
| Password Generator | `password_generator.py` | Generates a random password using Python's `secrets` module. |
| Password Strength Checker | `password_strength.py` | Checks a password against five basic criteria. |
| Python Quiz Game | `quiz_game.py` | Asks Python multiple-choice questions and calculates a score. |
| QR Code Generator | `qr_generator.py` | Creates a QR code image from text or a URL. |
| Rock Paper Scissors | `rock_paper_scissors.py` | Play the classic game against the computer. |

## How to Run

1. Install Python 3.
2. Open this folder in VS Code.
3. Open the terminal in VS Code.
4. Run a project, for example:

   ```bash
   python number_guess.py
   ```

For the QR Code Generator, install its optional dependency first:

```bash
python -m pip install "qrcode[pil]"
```

Then run:

```bash
python qr_generator.py
```

## Notes

These are educational command-line projects. Most projects keep data in memory, so entered data is not saved after the program exits. The ATM project is a simulation and is not connected to a real bank.
